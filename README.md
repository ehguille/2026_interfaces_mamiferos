# 2026_interfaces_mamiferos
Ejemplo para practicar herencias e interfaces

## Enunciado
Un animal puede ser mamífero o ave; los perros y los ornitorrincos son mamíferos. El gorrión es un ave y el pingüino también. Las aves y los ornitorrincos son ovíparos y pueden poner un número determinado de huevos. Los perros son vivíparos y pueden parir un número determinado de crías.
Todos los animales tienen nombre y peso; todos se alimentan (pero cada uno de forma distinta). No pueden existir "animales" genéricos, pero sí perros y ornitorrincos.
Cuando se cree un animal se debe indicar su nombre.
El programa debe crear un animal de cada tipo e imprimirse por pantalla con el método toString().
